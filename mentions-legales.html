Vos données

Ce site ne dépose aucun cookie de suivi. Le questionnaire « Voir mon site web » fonctionne entièrement dans votre navigateur : vos réponses et votre logo ne sont ni enregistrés ni envoyés par le site. Ils ne nous parviennent que si vous choisissez de nous écrire, depuis votre propre messagerie. Le site ne recueille donc vos données que si vous nous écrivez : nous utilisons alors votre message pour vous répondre, et nous ne le transmettons à personne pour de la publicité. Les polices du site sont chargées depuis Google Fonts, ce qui transmet votre adresse IP à Google. Comme tout hébergeur, GitHub reçoit votre adresse IP quand vous consultez le site.

Ce site ne dépose aucun cookie de suivi. Quand vous donnez votre email dans le questionnaire « Voir mon site web », GREENROCK (HOOD) enregistre cette adresse et vos réponses pour garder votre projet de site, vous envoyer le lien qui permet de le reprendre et vous montrer vos factures dans votre espace. Un compte sans mot de passe est créé à cette adresse. Ce traitement répond à votre demande, avant toute commande (mesures précontractuelles, article 6.1.b du RGPD). Votre logo reste dans votre navigateur et ne nous est pas envoyé.

Vos réponses sont effacées 180 jours après votre dernière visite si vous n'avez pas commandé. Les factures sont conservées le temps exigé par la loi.

Prestataires qui traitent ces données pour nous : Supabase (base de données, serveurs à Francfort), Purelymail (envoi du mail de connexion), Cloudflare (protection contre les robots sur la demande de lien), Stripe (paiement et factures). Certains de ces prestataires peuvent traiter des données hors de l'Union européenne. Les polices du site sont chargées depuis Google Fonts, ce qui transmet votre adresse IP à Google ; comme tout hébergeur, GitHub la reçoit aussi.

Vous pouvez demander l'accès à vos données, leur correction ou leur effacement à la même adresse e-mail. Vous pouvez aussi saisir la CNIL (cnil.fr).
